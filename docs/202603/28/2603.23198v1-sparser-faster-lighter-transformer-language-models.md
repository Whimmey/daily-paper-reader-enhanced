## 摘要
扩展自回归大型语言模型(LLMs)带来了前所未有的进步，但也伴随着巨大的计算成本。在这项工作中，我们通过利用LLM前馈层中的非结构化稀疏性来解决这些成本，这些组件占据了大部分模型参数和执行FLOPs。为此，我们引入了一种新的稀疏打包格式和一组CUDA内核，旨在与现代GPU的优化执行管道无缝集成，使LLM推理和训练期间能够高效进行稀疏计算。为了验证我们的改进，我们对LLM稀疏性进行了定量研究，证明简单的L1正则化可以诱导超过99%的稀疏性，而对下游性能的影响可以忽略不计。当与我们的内核结合使用时，我们表明这些稀疏性水平转化为显著的吞吐量、能源效率和内存使用优势，并且这些优势随着模型规模的增加而增加。我们将根据开源许可证发布所有代码和内核，以促进采用并加速研究，将稀疏性确立为提高现代基础模型效率和可扩展性的一个实用轴。

## Abstract
Scaling autoregressive large language models (LLMs) has driven unprecedented progress but comes with vast computational costs. In this work, we tackle these costs by leveraging unstructured sparsity within an LLM's feedforward layers, the components accounting for most of the model parameters and execution FLOPs. To achieve this, we introduce a new sparse packing format and a set of CUDA kernels designed to seamlessly integrate with the optimized execution pipelines of modern GPUs, enabling efficient sparse computation during LLM inference and training. To substantiate our gains, we provide a quantitative study of LLM sparsity, demonstrating that simple L1 regularization can induce over 99% sparsity with negligible impact on downstream performance. When paired with our kernels, we show that these sparsity levels translate into substantial throughput, energy efficiency, and memory usage benefits that increase with model scale. We will release all code and kernels under an open-source license to promote adoption and accelerate research toward establishing sparsity as a practical axis for improving the efficiency and scalability of modern foundation models.

## 1. 论文的核心问题与整体含义

大型语言模型(LLMs)的扩展带来了前所未有的进步，但也伴随着巨大的计算成本。前馈层(feedforward layers)占据了大部分模型参数和执行FLOPs，是计算成本的主要来源。现有稀疏计算方法存在效率问题，尽管理论上计算量减少，但实际运行速度往往比密集计算慢，这主要是由于非结构化稀疏性与GPU架构之间存在根本性不匹配。本研究旨在通过利用LLM前馈层中的非结构化稀疏性来解决这些计算成本问题，提高LLM的效率和可扩展性。

## 2. 论文提出的方法论

### 核心思想
利用LLM前馈层中的非结构化稀疏性来降低计算成本，通过引入新的稀疏打包格式和CUDA内核，与现代GPU优化执行管道无缝集成。

### 关键技术细节
- **TwELL稀疏格式**：提出Tile-wise ELLPACK (TwELL)稀疏格式，专为LLM推理和训练设计，将列分组为水平1D瓦片，在每个瓦片内使用基于ELL的打包格式
- **推理内核**：融合多个矩阵乘法到单个优化管道中，最小化计算，使用TwELL格式高效存储门控激活
- **训练内核**：将稀疏表示转换为混合格式(ELL+密集备份)，简化中间激活的存储成本，支持高效反向传播
- **稀疏诱导**：使用简单的L1正则化公式：L1 × (1/L)∑(l=1到L) (1/M)∑(m=1到M) (1/N)∑(n=1到N) |h^l[m,n]|，诱导高稀疏性

### 算法流程
1. 使用ReLU作为激活函数
2. 在标准交叉熵损失中添加L1正则化项
3. 推理时：门控投影→TwELL格式→融合的上投影和下投影
4. 训练时：门控投影→TwELL→混合格式→高效矩阵乘法→反向传播

## 6. 论文的主要结论与发现

### 主要结论
- 简单的L1正则化可以诱导超过99%的稀疏性，而对下游性能的影响可以忽略不计
- 结合专用内核，高稀疏性水平转化为显著的吞吐量(最高20.5%)、能源效率(最高21.9%)和内存使用(最高28.1%)优势
- 这些优势随着模型规模的增加而增加
- 稀疏性可作为提高现代基础模型效率和可扩展性的实用轴

### 重要发现
- 前几层激活较少，中间层激活较多，最后层激活再次减少
- 不同token激活模式差异很大，提供重要上下文信息的token激活更多
- 序列开始位置的token激活更多，之后呈指数下降
- 死神经元现象在高稀疏性下明显，约30%的神经元可能永久失活
- 稀疏性与层平均激活数呈强负相关(Pearson系数-0.996)
