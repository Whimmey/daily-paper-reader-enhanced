Abstract 

In this paper, we introduce GHOST -WRITE BENCH , a dataset for LLM authorship attribution. It comprises long-form texts (50K +

words per book) generated by frontier LLMs, and is designed to test generalisation across multiple out-of-distribution (OOD) dimen-sions, including domain and unseen LLM author. We also propose TRACE— a novel fingerprinting method that is interpretable and lightweight — that works for both open- and closed-source models. TRACE creates the fingerprint by capturing token-level transition patterns (e.g., word rank) estimated by another lightweight language model. Experiments on G HOST WRITE BENCH demonstrate that TRACE achieves state-of-the-art performance, remains robust in OOD settings, and works well in limited training data scenarios. 1

1 Introduction 

Recently, a large number of AI detection datasets have been proposed (Table 1). However, several limitations remain. First, most datasets frame de-tection as binary human vs. AI classification (He et al., 2024; Dugan et al., 2024), with only a few (La Cava and Tagarelli, 2025; Uchendu et al., 2021) supporting the authorship attribution (AA) task (i.e., multi-class classification). Second, they rarely evaluate generalisation (e.g., by including text gen-erated by unseen generators or text from other do-mains). Finally, existing datasets focus on short texts, even though we are beginning to see the emergence of LLM ghostwritten books (The Au-thors Guild, 2024; Australian Society of Authors, 2025). 2 In addition to these dataset limitations,

2 Related Work 

2.1 Authorship Attribution 

Authorship attribution (AA) is a long-standing field (Mendenhall, 1887; Mosteller and Wallace, 1963) that has grown with the rise of digital texts and advances in machine learning (Tyo et al., 2023; Stamatatos, 2009; Neal et al., 2017). It is usu-ally formulated as a multi-class classification prob-lem, with each class representing an author. Cur-rent SOTA methods rely on neural networks, often using transformer-based backbones fine-tuned on domain-specific corpora (Tyo et al., 2023; Fabien et al., 2020; Koppel and Schler, 2004). Despite their effectiveness, these approaches are resource-intensive, require careful dataset curation, gener-alise poorly to new domains, and struggle with long documents due to standard transformer (Vaswani et al., 2017) context limits (e.g., 512 tokens). 

2.2 LLM-Generated Text 

As LLMs are increasingly used to generate fabri-cated details or misinformation, provenance and veracity have become increasingly pressing (Ku-marage et al., 2024; Huang et al., 2025). Detecting LLM-generated text is non-trivial: humans often perform only slightly above chance (Clark et al., 2021; Dou et al., 2022; Uchendu et al., 2021). Most prior work (Mitchell et al., 2023; Yang et al., 2024; Wu et al., 2025) focuses on binary (human vs. ma-chine) classification, even though attribution to a specific model is important for accountability. Ex-isting SOTA methods (La Cava and Tagarelli, 2025; Guo et al., 2024) largely mirror traditional AA ap-proaches, inheriting limitations such as poor gener-alisation and lack of interpretability. Some works have explored cross-domain evaluation (Dugan et al., 2024; He et al., 2024; Wang et al., 2024). However, they consider only a limited set of authors and exclude LLM-generated text. Most assume a closed set of authors, whereas practical attribution often occurs in open-set scenarios (Stolerman et al., 2014; Huang et al., 2025). LLMs have also fostered ghostwriting, produc-ing content on someone’s behalf without authorship credit, contributing to low-quality or sham books impacting authors (The Authors Guild, 2024; Aus-tralian Society of Authors, 2025). Motivated by these developments and methodological limitations, our work focuses on improving the generalisation of attribution techniques for LLM-generated long-form documents such as books. 3

3 GHOST WRITE BENCH Dataset 

In this paper, we focus on the task of LLM au-thorship attribution for long-form documents, i.e., determining which LLM generated a given docu-ment. As shown in Table 1, most existing datasets of LLM-generated text focus on constrained set-tings, i.e., (i) framing the task as binary detection, (ii) without evaluating OOD generalisation, and (iii) focusing on short texts. 3.1 Book Generation Pipeline 

Humans typically write book through a hierarchi-cal process involving planning, drafting, and revi-sion (Sun et al., 2022; Lee et al., 2025; Hayes and Flower, 2016). We mimic this process by designing a book generation pipeline with incremental steps: outlining, summarisation, and long-text expansion, following prior works (Yao et al., 2019; Wang et al., 2025; Alhussain and Azmi, 2021). For each book, we first generate a detailed out-line conditioned on some constraints (e.g., era and genre); this outline produces the narrative struc-ture, plot, and characters. And then iteratively over multiple turns, we instruct the LLM to produce the next text segment, conditioned on the outline, the previous segment, and the running summary (prompts and more details in Appendix A.1). We provide real, human-authored texts (sourced from Project Gutenberg 5) as few-shot reference exam-ples to guide the LLM generation to maximise gen-eration quality (constraints such as era and genre are therefore drawn from these Gutenberg books). This pipeline ensures that narrative coherence and discourse structure are preserved, enabling the gen-eration of full-length books. 6 Table 2 provides some data and text quality statistics for these LLM-generated books (we will return to discuss more on how we evaluate quality in Section 3.3).

This creates a more challenging setting than using a single split shared across all authors, as commonly used in existing datasets (see Ap-pendix Table 10 for splits). Quality Analysis. We evaluate text quality using several metrics in Table 2. We measure perplexity (PPL) (Jurafsky and Martin, 2026) of generated texts for different LLMs, a standard measure of language understanding. We then measure several lexical diversity metrics, comprising both inter- and intra-document measures. We compute self-BLEU (S-B) (Zhu et al., 2018), a homogenisation score over pairs of books generated by the LLM (since we lack references), which is commonly used in writing tasks to ensure diversity (Padmakumar and He, 2024). It is common for LLMs to repeat text in long-form generation (Bai et al., 2025); hence, we evaluate self-repetition (S-R) (Salkar et al., 2022), which captures this repetition tendency. Similarly, we measure the N -gram diversity score (NGD) (Meister et al., 2023), which measures the num-ber of unique n-grams in the texts generated by LLMs. Finally, a non-n-gram-based compression ratio (CR) metric (Shaib et al., 2025a) evaluates compressibility (higher values suggest redundancy). Across all these diversity metrics, we observe that all LLMs in G HOST WRITE BENCH have values similar to those of human books, quantitatively in-dicating comparable text quality. In addition to quantitative analysis, we conduct a small-scale human evaluation on a subset of books (more details in Appendix A.3) with ten annotators. We assess quality across multiple dimensions, fol-lowing prior work (Xia et al., 2025; Chhun et al., 2022). Appendix Table 7 reports the average an-notator scores across different quality dimensions (see Appendix A.3 for definitions), both at the pas-sage level and overall for each book. Overall, we observe strong scores ( > 4; out of 5) for relevance, coherence, fluency, and diversity, complementing the text quality and diversity analysis presented above. Scores for other subjective dimensions (en-gagement, empathy, surprise, and complexity) are also generally positive ( > 3.3). These results indi-cate that the text in G HOST WRITE BENCH exhibits strong relevance and is of overall good quality .

Given a test sample, we then construct its fingerprint and determine whether it matches one of the reference fingerprints 10 .As different LLMs may have different prefer-ences when it comes to word selection during gener-ation, our idea is to examine token-level transitions, such as word rank (Section 4.1) and entropy (Sec-tion 4.2), as computed by a separate, lightweight

Capturing word prefer-ence is not new (perplexity does that) (Wu et al., 2025; Huang et al., 2025), but what is new here is that we want to look at how this preference transi-tions over time. As illustrated in Figure 1, we construct the fin-gerprint by modelling transitions between consec-utive tokens. The resulting two-dimensional ma-trix produces heatmaps that reflect distinctive writ-ing styles (see Appendix Figures 10 and 11). Our fingerprint TRACE can be applied to both open-and closed-source LLMs, since it does not require white-box access. It is lightweight and adaptable, and produces an interpretable 2D signature. We next discuss these two variants of TRACE: rank-based and entropy-based.

For each token ti ∈ ⟨ t1, t 2, . . . , t m⟩, we compute its rank ri under an evaluator language model Lˆθ.The raw fingerprint ˆf rank ∈ R|V|×|V| captures the counts of (ri−1, r i) (Figure 1). This fingerprint ma-trix is very large and sparse, and so we compress it by binning ranks into equal probability clusters (as detailed in Appendix Algorithm 1), giving the final fingerprint f rank ∈ RK×K where K ≪ |V| .We apply this fingerprint construction process for each LLM using their training books (if an LLM has multiple books, one fingerprint is created for each book) to create reference fingerprints for each LLM. Then, for a test text, we construct a test fingerprint following the same process above. To determine which LLM generated the test text, we identify the reference fingerprint that is most similar to the test fingerprint. To measure similarity between two fingerprints, which can be interpreted as discrete probability dis-tributions, we use the Jensen-Shannon (JS) distance (equation given in Appendix B.1). 54.2 Entropy-Based

5 Experimental Setup 

Baselines. We consider techniques from different areas and categories as baselines. From metric-based methods, we evaluate R ANK , E NTROPY ,and GLTR (Mitchell et al., 2023; Gehrmann et al., 2019; Su et al., 2023; La Cava and Tagarelli, 2025). Although originally designed for binary classifica-tion, we follow La Cava and Tagarelli (2025) to adapt them for multi-class classification (by learn-ing a threshold for each LLM). Experimental Setting. We use GPT-2 (smallest version; 124 M parameters) (Radford et al., 2019) as the independent evaluator language model to estimate word ranks and entropy for creating the fingerprints. Evaluation. Authorship attribution techniques are typically deployed in open-set settings, where the author of a test text may not appear among those seen during training (G HOST WRITE BENCH 

captures this with OOD-Author evaluation). In such cases, a reliable technique should be well-calibrated, assigning high confidence to known authors and low confidence to unseen ones (i.e., rejection) (Scheirer et al., 2012; Guo et al., 2017). To achieve this, we calibrate all methods (baselines and our methods) on the development set to de-termine a confidence threshold that best balances rejection and attribution performance. During eval-uation, we apply this threshold across all scenarios: ID, OOD-Domain, and OOD-Author for fair com-parison (in a practical application, we would not know whether a test text is ID or OOD, and so this thresholding would have to be applied at all times). For texts from known authors, predictions below the threshold are treated as false negatives (missed attributions); for unseen authors, such pre-dictions correspond to correct rejection. All thresh-olds for different configurations can be found in Appendix Table 16. Attribution performance is evaluated using the macro-F 1 metric, which assigns equal weight to all LLMs (Uchendu et al., 2020; Tyo et al., 2023).

6.2 Ablation Study Impact of Evaluator Language Model. We in-vestigate the impact of using different evaluator language models ( Lˆθ), which form the main com-ponent of TRACE. These models are used to com-pute scores (rank and entropy) for each token, as defined in Section 4. We evaluate two other 1B models, OLMo and Gemma ,12 which differ in architec-ture, type, and size compared to GPT-2 used in our experiments. We observe no major performance differences across these language models (see Ap-pendix Table 14). This suggests that TRACE ex-hibits considerable robustness to the choice of eval-uator language model.

7 Conclusion 

We propose G HOST WRITE BENCH , an authorship attribution dataset for long-form LLM texts. To test generalisation, G HOST WRITE BENCH exam-ines two OOD settings: OOD-Domain and OOD-Author. We also introduce TRACE, a novel, in-terpretable fingerprint method for LLM attribution. TRACE uses token-level transition patterns, such as word ranks and entropy, to create text finger-prints. Our experiments demonstrate the effective-ness of TRACE in ID, OOD, and limited training data scenarios in G HOST WRITE BENCH . Our re-search provides a new benchmark that explicitly tests for generalisation and new methods that have strong generalisation capability, paving the way for future research directions in LLM text forensics. 

Limitations 

GHOST WRITE BENCH is limited to English texts only; we plan to extend this dataset with cross-lingual OOD dimensions in future work. It would be interesting to study the effectiveness of TRACE in an OOD-language setting. Similarly, there are other OOD dimensions, such as time, human-authors, and others, which are natural extensions 8of G HOST WRITE BENCH . Since TRACE is not a supervised method, we expect it to be less prone to obfuscation attacks. Still, future work needs to study the resilience of TRACE against these at-tacks. Finally, adapting TRACE for fewer (<10K) tokens remains an open problem. We also focus only on a single-authorship setup. A natural next step would be to study multi-authorship (i.e., a piece of text written by multi-ple authors), which is more common in long-form documents that typically involve collaborative writ-ing. Finally, although the books generated by our pipeline are of good quality, we acknowledge that book generation and related aspects, such as cre-ativity, self-reflection, rewriting, etc., constitute re-search problems in their own right and fall outside the scope of this work. 

Ethics Statement 

GHOST WRITE BENCH contains LLM-generated books across various genres. The content of these books may include writing or plot elements that re-flect undesirable values. That said, all LLMs used incorporate built-in guardrails, so the likelihood of such issues should be minimal. This is further supported by our small-scale quality annotation, where no annotators identified any issues.

A.2 Quantitative Analysis 

In addition to the standard language understanding metric, perplexity, we evaluate several text diversity metrics as mentioned in Table 2. Considering we are operating in a reference-free setup, we focus on two prominent types of text diversity metrics, similarity between text pairs from the same model, and the token/type ratio (Shaib et al., 2025a): • Self-BLEU : Self-BLEU measures similarity between all text pairs using BLEU (Zhu et al., 2018). It is a homogenisation score widely used to evaluate text diversity in writing tasks (Padmakumar and He, 2024). • N -Gram Diversity Score : This token-type ratio metric (Meister et al., 2023) calculates the ratio of unique n-grams to all n-grams in the dataset. In our analysis, we consider 

n-grams of length four. • Self-repetition : Self-repetition (Salkar et al., 2022) measures the number of n-grams (up to 

4-grams) that repeat across multiple outputs of the same model. • Compression Ratio : Defined as the ratio of the compressed file size (using gzip) of all LLM-generated texts to the original file size, this metric captures redundancy in a manner distinct from n-gram-based measures (Shaib et al., 2025b). • Perplexity : We compute the average perplex-ity (Jurafsky and Martin, 2026) of model texts using the GPT-2-Large language model as a standard measure of language understanding.

D Baselines (cont.) 

Rank. We compute the average token rank for a given text using the GPT-2-Medium model. 

Entropy. Similarly, we compute the average to-ken entropy for a given text using the evaluator model, GPT-2-Medium .

GLTR. GLTR (Gehrmann et al., 2019) com-putes the probability of a token falling into four rank ranges (or buckets). Compared with a single average-based metric, it is more representative. For all three above metric-based techniques, we adapt them to the AA task following La Cava and Tagarelli (2025) by attaching a logistic regression classifier on top of these metric values. 

> N

-GRAM . This is a traditional but effective technique that ensembles three n-gram models: character-based, part-of-speech-based, and sum-mary statistics. Moreover, it can naturally handle long texts, so no chunking is required, unlike the next two methods. 

BERT -AA. A multi-class classification layer is added to the pre-trained BERT model (Fabien et al., 2020), which is then fine-tuned on a specialised dataset. However, as a Transformer-based archi-tecture (Vaswani et al., 2017), it has a bottleneck of processing at most 512 tokens at a time (Devlin et al., 2019). 

DETECTIVE . This is a contrastive learn-ing–based state-of-the-art method for binary AI detection (Guo et al., 2024). However, it internally learns representations for each author. Therefore, these embeddings can also be used for the AA task.
