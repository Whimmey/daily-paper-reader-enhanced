## 摘要
在图像复原中，单步判别式映射通过期望学习往往缺乏精细细节，而生成式范式则受困于低效的多步采样和噪声-残差耦合问题。为了解决这一困境，我们提出了 IR-Flow，这是一种基于矫正流的新型图像复原方法，作为一个统一框架弥合了判别式与生成式范式之间的差距。具体而言，我们首先构建了多级数据分布流，扩展了模型从不同退化级别中学习并适应它们的能力。随后，我们提出了累积速度场来学习跨越不同退化级别的传输轨迹，引导中间状态向清晰目标靠拢；同时，我们提出了多步一致性约束以强制轨迹的一致性，并提升少步复原性能。我们表明，直接在退化图像域和清晰图像域之间建立线性传输流，不仅能够实现快速推理，还提高了对分布外退化的适应性。在去雨、去噪和雨滴去除任务上的广泛评估表明，IR-Flow 仅需少量采样步数即可取得具有竞争力的定量结果，提供了一个高效且灵活的框架，并保持了出色的失真-感知平衡。我们的代码可在 https://github.com/fanzh03/IR-Flow 获取。

## Abstract
In image restoration, single-step discriminative mappings often lack fine details via expectation learning, whereas generative paradigms suffer from inefficient multi-step sampling and noise-residual coupling. To address this dilemma, we propose IR-Flow, a novel image restoration method based on Rectified Flow that serves as a unified framework bridging the gap between discriminative and generative paradigms. Specifically, we first construct multilevel data distribution flows, which expand the ability of models to learn from and adapt to various levels of degradation. Subsequently, cumulative velocity fields are proposed to learn transport trajectories across varying degradation levels, guiding intermediate states toward the clean target, while a multi-step consistency constraint is presented to enforce trajectory coherence and boost few-step restoration performance. We show that directly establishing a linear transport flow between degraded and clean image domains not only enables fast inference but also improves adaptability to out-of-distribution degradations. Extensive evaluations on deraining, denoising and raindrop removal tasks demonstrate that IR-Flow achieves competitive quantitative results with only a few sampling steps, offering an efficient and flexible framework that maintains an excellent distortion-perception balance. Our code is available at https://github.com/fanzh03/IR-Flow.

### 论文提出的方法论

*   **核心思想**：
    *   基于矫正流构建一个常微分方程（ODE）框架，直接在退化图像分布（$\pi_1$）和清晰图像分布（$\pi_0$）之间建立线性传输流。通过学习速度场来引导从退化状态到清晰状态的转换，从而实现快速推理。
*   **关键技术细节**：
    1.  **多级数据分布流**：
        *   通过线性插值构建中间状态：$X_t = tX_1 + (1-t)X_0$，其中 $X_1$ 为退化图像，$X_0$ 为清晰图像，$t \in [0,1]$。
        *   这种构造方式不仅模拟了不同退化级别的中间状态，增强了模型对分布外（OOD）退化的适应性，而且当 $t=1$ 时，该方法退化为传统的判别式映射。
    2.  **累积速度场**：
        *   标准矫正流学习的是瞬时切向速度 $v(X_t, t) = X_1 - X_0$。
        *   论文提出累积速度场 $\hat{v}(X_t, t) = X_t - X_0 = t(X_1 - X_0)$。该速度场直接指向目标状态 $X_0$。
        *   **优势**：在最优传输能量上，CVF 的能量仅为标准速度场的 $1/3$，这降低了建模复杂度，显著加速了训练收敛，并提升了生成质量。
    3.  **多步一致性约束**：
        *   为了确保多步求解时的轨迹保持在直线路径上，引入了一致性损失 $L_{MCT}$。
        *   该损失通过 ODE 求解器（如欧拉法）从中间状态重构目标图像，并计算与真实清晰图像的误差，强制速度场方向与线性路径对齐。
    4.  **总体损失函数**：
        *   $L = L_S + \lambda_{MCT} L_{MCT}$，其中 $L_S$ 是累积速度匹配损失，$\lambda_{MCT}$ 为权重系数（实验设为0.3）。

### 论文的主要结论与发现

*   IR-Flow 成功构建了一个连接判别式和生成式图像复原的统一框架。
*   提出的累积速度场（CVF）相比标准矫正流速度场，能显著降低传输能量，加速模型收敛，并在图像生成任务中表现出色。
*   仅需极少的采样步数（如 1-4 步），IR-Flow 即可在多个复原任务上达到与需要上百步的 SDE 方法相当甚至更优的性能，实现了极佳的失真-感知平衡。
*   该方法对分布外（OOD）的退化级别具有更强的适应性和鲁棒性。

### 优点

*   **统一框架**：将判别式映射视为特例（$t=1$），理论框架优雅且具有普适性。
*   **高效推理**：基于 ODE 的线性传输流避免了复杂的噪声-残差耦合，推理速度极快（比 IR-SDE 快 100 倍）。
*   **创新的速度场设计**：累积速度场（CVF）不仅物理意义明确（指向目标），而且在数学上证明了其能量效率，有效解决了标准 RF 收敛慢的问题。
*   **卓越的泛化能力**：多级数据分布流的设计使得模型能更好地适应未见过的退化强度。

### 不足与局限

*   **缺乏语义引导**：目前方法仅基于图像信息，对于严重退化或遮挡区域，缺乏文本等语义信息的引导，复原效果可能受限。
*   **依赖成对监督数据**：当前框架基于监督学习，依赖成对的训练数据，在真实世界无配对数据的场景下应用受限（作者计划未来探索自监督学习）。
*   **范式灵活性**：目前主要基于 ODE 范式，未来需要进一步探索如何灵活切换或结合 SDE 范式以适应更复杂的需求。
